Ini adalah tulisan pertama di website pribadi saya.

Saya membuat website ini sebagai tempat yang lebih permanen untuk menyimpan tulisan, catatan, dan hal-hal yang saya kerjakan. Tidak bergantung pada algoritma media sosial, tidak perlu dashboard yang rumit, dan seluruh sumbernya tersimpan di GitHub.

## Kenapa GitHub Pages?

Untuk kebutuhan website pribadi yang sederhana, GitHub Pages sudah lebih dari cukup. Saya dapat menyimpan artikel dalam format Markdown dan GitHub/Jekyll akan mengubahnya menjadi halaman web.

Ke depan, saya akan menggunakan bagian **Blog** untuk tulisan yang lebih lengkap dan bagian **Notes** untuk catatan yang lebih pendek.

Ini baru permulaan.
